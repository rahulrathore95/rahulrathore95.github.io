03How I work
1.

Bad data gets quarantined, not loaded. Quality gates run before anything lands in the warehouse. Rows that fail checks go to a quarantine table with the reason attached - dashboards stay clean and nothing disappears silently.

2.

Fix what's fixable, escalate with context. Automated remediation handles the known failure modes. When a circuit breaker trips, the incident log carries the failing checks, the diagnosis and everything already tried - nobody starts from a blank pager.

3.

Re-runs are safe. Idempotent loads and audit logs mean a pipeline can be re-run at 3am without a second thought, and every automated action is traceable afterwards.

4.

Governance is part of the build. Lineage and data-quality rules ship with the pipeline (Purview on my Azure work), not as a cleanup project six months later.
